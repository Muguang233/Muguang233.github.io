链表的基本概念

C语言 数据结构
C语言
发布日期:   2025-07-17

前言

什么是链表

链表的正规定义是一种线性数据结构，其中的每个元素都是一个节点对象，各个节点通过“引用”相连接 来源
但是简单来讲，链表是由N个节点组成的一个结构，每个节点会包含两种内容：

  1. 储存的数据类型
  2. 一个指针，指向下一个节点在内存空间中的地址

数据类型可以是任何数据类型，是用户自定义的，可以是整数，可以是字符串，甚至可以是一个结构体
在C语言中创建链表，首先我们需要一个结构体来封装每个节点

struct Node {
  int data;
  char name[20];
  struct Node* next;
};

C语言链表的节点结构体通常会用Node来命名，注意的是这不是强制性的，结构体声明是自定义的，同时节点的结构体中必须包含一个指针指向下一个节点的地址保证链表的连续性，但是在内存空间中，每个节点的位置是不连续的，并且链表的头节点必须保存在一个可以访问到的位置
大多数人对链表的概念会是这样的

但是在物理内存中(图内包含以上结构体声明)是这样的


链表的地址(通过malloc申请)是系统决定的，所以在物理内存中，他们是分散在各地的(可能会是线性的 取决于调用malloc的位置)，每个节点中的next指针的作用也是保存在内存空间中下一个节点的地址来保证链表的连续性，并且链表最后一个节点的next指针会是NULL来停止遍历链表

创建链表

创建节点

现在我们声明一个节点创建的函数签名，我们将函数的类型声明为struct Node*指针类型，传入的参数为结构体里保存的数据int data, char name[20]，函数定义中用malloc在堆空间内申请空间来保存节点，具体可以看这篇文章 初始化新节点的数据，并返回新节点的地址

struct Node* newNode(int data, char *name) {
  struct Node* new = malloc(sizeof(struct Node));//<stdlib.h>
  if(new == NULL) return NULL;//申请失败
  new->data = data;
  new->next = NULL;
  strcpy(new->name, name);//<string.h>
  return new;
}

在newNode中我们创建了一个临时指针作为malloc函数返回值的载体并且最后返回到调用newNode的地方
注意：next下一个节点的指针在创建节点时最好初始化为NULL以便后续的使用
完整的代码实现会是以下这样

#include<stdio.h>
#include <string.h>
#include<stdlib.h>
struct Node {
  int data;
  char name[20];
  struct Node* next;
};
struct Node* newNode(int data, char *name) {
    struct Node* new = malloc(sizeof(struct Node));//<stdlib.h>
    if(new == NULL) return NULL;//申请失败
    new->data = data;
    strcpy(new->name, name);//<string.h>
    return new;
}
void print_struct(struct Node node) {
  printf("data = %d\n", node.data);
  printf("name = %s\n", node.name);
}
int main() {
  struct Node* head = newNode(100, "Jack");
  head->next = newNode(2000, "Nick");
  head->next->next = newNode(2000, "Wick");
  printf("head(节点1) 地址 = %p\n", head);
  print_struct(*head);
  printf("节点2地址 = %p\n", head->next);
  print_struct(*head->next);
  printf("节点3地址 = %p\n", head->next->next);
  print_struct(*head->next->next);
}

控制台输出

head(节点1) 地址 = 0x5560462152a0
data = 100
name = Jack
节点2地址 = 0x5560462152d0
data = 2000
name = Nick
节点3地址 = 0x556046215300
data = 2000
name = Wick

分析这段代码，我在函数print_struct的参数中并没有用指针来接收链表中节点的地址，因为我的目的并不是修改节点中的值，所以我只需要复制到局部变量即可，同时因为我的参数不是指针，在调用的时候就需要*运算符解引用

那么如果我用指针来接收是不是能让整个流程变得轻松点？ 是的 以上代码可以用遍历链表来实现，同时也是大多数人操作链表的方式

链表操作

遍历链表

我们先不考虑用遍历来添加和创建节点，只将print_struct改为遍历方式

void print_struct(struct Node *head) {
  struct Node* curr = head;
  int index = 1;
  while(curr != NULL){
    printf("节点%d = %p\n", index, curr);
    printf("data = %d\n", curr->data);
    printf("name = %s\n", curr->name);
    curr = curr->next;
  }
}
int main() {
  struct Node* head = newNode(100, "Jack");
  head->next = newNode(2000, "Nick");
  head->next->next = newNode(2000, "Wick");
  print_struct(head);
}

节点1 = 0x564e56bf22a0
data = 100
name = Jack
节点1 = 0x564e56bf22d0
data = 2000
name = Nick
节点1 = 0x564e56bf2300
data = 2000
name = Wick

->的意思可以看这篇文章对结构体指针的介绍
我们将print_struct的参数改为结构体指针，那么main里我们调用时传递的参数就是我们头节点的地址
回到print_struct的视角中，我们只有一个头节点的地址保存在参数里，这个时候链表的特性就来了，我们链表的每一个节点中都有一个指针指向下一个节点的位置，这个时候，为了安全性，我们声明一个临时指针指向和头节点同样的地址用于遍历

注意：两个指针可以指向同一个地址，如果不了解可以再看一下指针的文章
因为我们需要用到每一个节点的信息来作为控制台输出，那么while循环的条件就是curr != NULL

注意：在创建节点时我们已经将所有next指针初始化为NULL
每次使用完当前节点，我们就需要让临时指针curr指向下一个节点，也就是curr = curr->next 假设在这一个操作之前curr指向节点1，那么在curr = curr->next之后，curr指向的就是节点2，以此类推一直到curr指向的是NULL时停止循环

尾部插入

我们可以用同样的方式来简化创建新节点的方式，像打印一样，只传入头节点，并且一直遍历到最后一个节点之后添加节点

void append_list(struct Node* head, int data, char *name) {
  struct Node* curr = head;
  while(curr->next != NULL) {
    curr = curr->next;
  }
  curr->next = newNode(data, name);
}
int main() {
  struct Node* head = newNode(100, "Jack");
  append_list(head, 2000, "Nick");
  //head->next = newNode(2000, "Nick");
  append_list(head, 2000, "Wick");
  //head->next->next = newNode(2000, "Wick");
  print_struct(head);
}

我们注意到append_list中，循环条件和打印不一样，首先我们要分析自己的需求，我们要在尾部添加一个新节点，如果还是继续使用curr != NULL作为循环条件，当跳出循环时，我们的curr指向的是什么? 是NULL，也就是跳出了链表范围，所以当我们用curr->next != NULL作为循环条件时，curr在跳出循环时会在最后一个节点

注意：因为我们创建时将所有next指针初始化为NULL并且在添加节点的图中将前面的节点的next指针赋值为了新节点的地址，所以链表的最后一个节点中保存的next指针必定为NULL

链表释放

在这篇文章中我们提到，使用malloc是向堆空间申请空间，在使用完需要释放回去，不然会造成内存泄漏

释放内存的函数为free(参数)并且他的参数是一个指针，很多人处理内存释放时，只释放了head头节点的地址，而没有释放链表中所有申请的内存空间，这样会造成很严重的内存泄漏，就像以下错误示范

free(head);

而正确释放链表空间，同样需要遍历整个链表

void free_list(struct Node* head){
  struct Node* curr = head;
  while(curr != NULL) {
    struct Node* temp = curr;
    curr = curr->next;
    free(temp);
  }
}

我们接收的参数只有一个指针指向头节点struct Node* head，这个时候我们声明一个临时指针curr用于遍历链表，但是为什么我们还需要声明一个临时指针temp呢？
如果我们不创建一个临时指针temp来保存当前节点的地址而是用free(curr)的话，无论是在调用free(curr)之前还是之后使用curr = curr->next，都会跟丢我们的链表
即使我们声明了一个临时指针temp 我们也需要在free(temp)之前移动curr,假设我们不移动，这时curr和temp都指向节点1，并且我们直接释放free(temp)的话，我们的指针curr指向的还是节点1的空间，这时候curr = curr->next也会变得不合法，因为他指向的空间已经被释放了

想查看内存泄漏，linux可以通过sudo apt-get install valgrind下载valgrind并且使用这个命令行valgrind --leak-check=full [你的程序文件]
