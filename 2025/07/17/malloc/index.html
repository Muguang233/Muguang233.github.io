动态内存分配

malloc是什么

malloc是C语言标准库<stdlib.h>中的一个函数，通常用在申请栈空间以外的内存，可以想成先在程序的堆空间内申请一块空间，如果堆空间也溢出，程序会向系统继续动态分配额外的堆空间

为什么要用malloc

malloc的一个作用就是防止栈空间溢出(初步了解内存可以看这篇文章)，通常栈空间在64位中是8MB的大小，以下代码就可以诠释什么叫栈空间溢出

#include <stdio.h>
void overflow(int n) {
  int arr[n];
  printf("arr的大小 = %zu\n", sizeof(arr));
}
int main() {
  int n;
  scanf("%d", &n);
  overflow(n);
  return 0;
}

当n的数量过大，就会造成栈溢出
如果我们输入一个1500000 在64位中并不会溢出，但是在32位中就会溢出，因为32位的栈空间分配大多是4MB

1500000
arr的大小 = 6000000

如果再次运行

3000000
Segmentation fault (core dumped)

这样就会栈溢出，因为3000000个int远远超出了栈空间分配的大小

C语言中，链表操作会需要用到malloc，但是很多人可能觉得我只需要知道需要用就行而不需要知道为什么要用malloc 所以有没有别的方式可以代替malloc，以下代码就是一个错误示范

#include <stdio.h>
struct node {
  int data;
  struct node *next;
};
struct node* new_node(int val){
  struct node new = {val, NULL};
  return &new;
}
int main() {
  struct node* head = new_node(10);
  head->next = new_node(20);
  printf("%d\n%d\n", head->data, head->next->data);
  return 0;
}

这里先卖个关子，下个小节会讲解为什么这是一个错误示范，也可以在这里停下来尝试自行编译查看错误信息

使用malloc

返回类型

我们分析malloc的函数签名，如果没了解过函数基本概念可以看这篇文章，首先malloc的返回类型是一个void*。我们知道void是无类型，代表不需要一个特定的返回类型，甚至不需要返回值，在这里void* 代表的是一个指向未知数据类型的地址的指针，他不需要一个特定的数据类型例如int, double, char，同时也不能通过*指针运算符来解引用并读出保存在地址的值，恰好匹配了malloc申请内存空间的特性。在调用了malloc申请空间后，申请到的空间会以地址的形式作为返回值，如果malloc申请失败(一般不会发生，除非系统也没空闲资源来分配)，便会返回一个NULL

参数

在malloc的参数中，有一个size_t _size,这个代表了申请的大小
例如以下代码

char* p = malloc(10000)

就会在堆空间内申请大小为10000字节的内存空间

范例

以下代码很好的展示当malloc成功申请到一片堆内存中的空间并返回它的地址以及当申请空间过大而返回NULL

#include<stdio.h>
#include<stdlib.h>//malloc方法所在的库 必须添加
int* try_allocate(size_t size) {
  int* ptr = malloc(size);
  if(ptr == NULL) {
    printf("分配失败\n");
    return NULL;
  }
  return ptr;
}

int main() {
  int* ptr_success = try_allocate(1000);
  printf("地址 = %p\n", ptr_success);
  int* ptr_fail = try_allocate(200000000000);
  printf("地址 = %p\n", ptr_fail);
}

地址 = 0x5556a22832a0
分配失败
地址 = (nil)

在这里我定义了一个函数来封装我想要的功能， 当我们编译并运行时能看到控制台的输出，我第一次尝试分配内存时分配了1000字节，并且他成功地返回了堆内存中的地址，但第二次的申请过大，系统并没有分配，所以会返回一个NULL，那么在我的函数中也就需要返回一个NULL回到main

合理运用malloc

上述使用malloc的方式并没有那么合理，通常使用malloc不会直接给常量，而是规划我们真正需要的空间大小再进行计算与分配，动态内存分配在c语言标准库中有两个函数方法，一个是malloc，另外一个是realloc，第二个我们后面再讲解，现在我们先了解另一个使用malloc的方式

首先我们声明一个结构体Student

struct Student{
  int id;
  double weight;
  char name[20];
};

例子的目的是，在main函数中声明一个指针指向大小为2个结构体Student的数组，并且在初始化数组中元素的值之前使用malloc在堆内存中分配地址
之前提到，我们通常会按照具体的需求来分配相应的内存大小，那么我们会使用到sizeof来计算并获取一个变量或数据的大小，在这个例子中，我们想要的大小是两个Student结构体的大小，那么我们的代码实现就会是这样的

struct Student* student_list = malloc(2*sizeof(struct Student));

在指针拓展中我们提到了数组与指针之间的关系，我们声明的指针struct Student* student_list同样也是一个struct Student数组，然后我调用了malloc并且传入的大小是2*sizeof(struct Student) 数字2对应的是申请的数组大小，sizeof(struct Student)是Student结构体的大小，如果要计算的话就会是4+8+20对应的是结构体中每个成员变量的大小，我们的初始化代码实现就是这样的

#include<stdio.h>
#include<stdlib.h>//malloc方法所在的库 必须添加
#include<string.h>
struct Student{
  int id;
  double weight;
  char name[20];
};
struct Student new_student(int id, double weight, char *name){
  struct Student new = {id, weight};
  strcpy(new.name, name);
  return new;
}
int main() {
  struct Student* student_list = malloc(2*sizeof(struct Student));
  student_list[0] = new_student(1, 10.0, "Jack");
  student_list[1] = new_student(2, 20.0, "Nick");
  for(int i = 0; i < 2; i++) {
    printf("student id = %d\nweight = %.2lf\nname = %s\n", student_list[i].id, student_list[i].weight, student_list[i].name);
  }
}

realloc

什么是realloc

在c语言标准库<stdlib.h>中对于realloc的声明中，第一个参数是接收指针指向需要被重新分配空间的地址，第二个参数是需要重新被分配的大小
继续上个小节的代码，这次我们想将student_list变成大小为3的数组，如果我们只是单纯地继续调用student_list[2] = new_student(3, 30.0, "Nio)，这是不合法的，因为越界了，我们在先前malloc申请的大小只有2个Student结构体，这个时候就会体现出realloc的作用

student_list = realloc(student_list, 3*sizeof(struct Student));
student_list[2] = new_student(3, 30.0, "Nio");

首先student_list本身就是一个指针，指向这一组数据在内存中的地址，那么我们将student_list作为realloc返回值的载体，重新分配一个3*sizeof(struct Student)的大小，这时我们再调用student_list[2] = new_student(3, 30.0, "Nio)就是合法的

释放

无论是malloc还是realloc，都需要在使用完申请的内存空间地址之后释放申请的内存，因为申请的是堆空间内甚至是系统资源，如果在程序终止后没有释放内存的话，会造成内存泄漏
为了避免内存泄漏，我们需要释放申请的内容，但是大多数初学者(虽然说我也是)会混淆一个概念，我们要释放的是什么？这里要注意，我们该释放的是地址而不是指针
假设我们有两个指针指向同一个通过malloc申请的堆内存空间**，我们只需要任意使用一个指针来释放地址即可

int* ptr = malloc(sizeof(int));
int* _ptr = ptr;
free(_ptr); //或free(ptr)
